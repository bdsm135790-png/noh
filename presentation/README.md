# 발표 자료 — 군집 소방 드론 × 실주소 화재확산 시뮬레이션

제6회 빅데이터로 우리동네 문제해결 아이디어 공모대회(창원시) 발표용 슬라이드.

- `창원_군집소방드론_발표.pptx` — 발표 슬라이드 16장 (10분 발표 분량, 다크 테마)
- `generate_deck.js` — 슬라이드를 생성하는 pptxgenjs 스크립트 (재생성용)

## 구성 (6섹션 · 16장)

1. **표지** — ①
2. **기획 배경 및 문제 정의** — ② 배경 · ③ 문제 정의 · ④ 현장 데이터(진입불가 10곳)
3. **기술 스택 및 데이터 파이프라인** — ⑤ 파이프라인 · ⑥ 기술 스택
4. **화재 확산 시뮬레이션** — ⑦ 원리 · ⑧ 5국면 · ⑨ 시연 4컷 · ⑩ 대응시간 비교
5. **드론 군집 로직 시뮬레이션** — ⑪ Boids · ⑫ 역할 기반 · ⑬ A*·좌표변환 · ⑭ 통합 시나리오
6. **기대효과** — ⑮ 핵심 성과 · ⑯ 기대효과·마무리

## 재생성

```bash
npm install pptxgenjs
node generate_deck.js 창원_군집소방드론_발표.pptx
```

## 발표 전 채워 넣을 값

- 표지의 **발표자·팀명·연도**
- ⑩ 대응시간, ⑮ 피해 저감률 등 **수치는 예시 시나리오**(마산어시장·드론 6대·풍속 3m/s·밀집도 88%).
  실제 시뮬레이션(HTML)에서 뽑은 값으로 교체 권장.
