# 발표 자료 — AI 드론·UGV 협업 도심 화재 정밀 진압 모델

**제6회 빅데이터로 우리동네 문제해결 아이디어 공모대회(경남)** 발표용 슬라이드.
주제(자유·방산융합): *AI 기반 드론–지상 무인차량(UGV) 협업 시스템을 활용한 도심 화재·재난 현장 정밀 진압 모델*.
팀 **군체** — 한태영·김상도·노현수 (경상국립대학교 USG융합전공 방산시스템).

## 덱 두 종류

**A. 다크 피치 덱** — `창원_군집소방드론_발표.pptx` (17장, 다크 테마)
- `generate_deck.js` 로 생성. 6섹션 발표용(아래 구성).

**B. 밝은 데이터 분석 리포트 덱** — `화재빅데이터_드론배치_분석리포트.pptx` (14장, 라이트 테마)
- `generate_report_deck.js` 로 생성. bigdata-119 활용사례 느낌의 인포그래픽/차트형.
- **2부 구성**: PART 1 데이터 분석 → 드론 배치 소방서 선정 / PART 2 도착 후 대응 로직.
  - PART 1: ①데이터 수집(소방안전 빅데이터 플랫폼) → ②지역 선정=창원(경남 시·군별 화재건수, 창원 563건 최다) → ③지도·경로 분석(화재지점 표시·소방차 진입불가 경로 빨간선) → ④창원 구별 화재·종합 위험지수 → ⑤거점 소방서 선정(위험 히트맵)
  - PART 2: ①출동·도착(대응시간) → ②5개 편대 전개 → ③SOP-D 5단계 → ④3D 현장 대응 → 확장(UGV)+기대효과
  - 화재건수는 소방안전 빅데이터 플랫폼 최근 1년 경남 통계 실측값(창원 563 / 김해 457 / 진주 318 …, 창원 구별 의창126·진해117·마산합포116·성산116·마산회원88).

## 구성 (6섹션 · 17장)

1. **표지** — ①
2. **기획 배경 및 문제 정의** — ② 배경(원도심·고령) · ③ 문제 정의(진입불가·1인1기·복사열) · ④ 해결 접근(방산 스핀오프)
3. **기술 스택 및 데이터 파이프라인** — ⑤ 실행계획 2단계 · ⑥ 분석용 빅데이터(KOSIS·data.go.kr·건축물대장) · ⑦ 구현 기술 스택
4. **화재 확산 시뮬레이션** — ⑧ 원리 · ⑨ 시연 4컷 · ⑩ 대응시간 비교
5. **드론 군집 로직 시뮬레이션** — ⑪ 군집 자율비행 · ⑫ 5개 편대 편성 · ⑬ SOP-D 5단계 · ⑭ 3D 건물 시연 · ⑮ 유무인 복합(UGV)
6. **기대효과** — ⑯ 핵심 성과 · ⑰ 기술·사회·지역 3측면 + 마무리

## 근거 자료

- 공식 아이디어 계획서(HWP): 팀·주제·추진배경·실행계획·분석용 데이터·기대효과
- `fire_drone_ops_2.html`: 드론 군집 SOP-D 시뮬레이션(5개 편대·SOP 5단계·3D 건물)
- `실주소 도면 기반 화재확산 시뮬레이션(v5).html`: 화재확산 격자 모델·대응시간 비교
